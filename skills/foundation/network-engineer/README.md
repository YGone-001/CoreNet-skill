# Network Engineer

An independently usable Foundation Skill for general IP and transport-network investigation. It teaches network-path methodology rather than application or telecom procedure semantics.

Use it for routing, DNS, reachability, transport behavior, MTU, NAT, firewall, latency, and loss questions. Do not use it to diagnose protocol semantics or assign end-to-end failure ownership.

The complete standalone package includes local CoreNet contracts, integrity records, and immutable `upstream/` material. No repository-root files or other Skills are required.

Telecom-specific extensions are not included yet. Upstream provenance is recorded in `UPSTREAM.md`.
