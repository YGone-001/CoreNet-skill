# C Pro

An independently usable Foundation Skill for general C systems-programming and debugging methodology. It supports evidence-based engineering without mapping any product-specific codebase.

Use it for memory ownership, control flow, diagnostics, debuggers, sanitizers, and focused validation. Do not use it for source-tree mappings or protocol parser knowledge.

The complete directory is standalone: it includes CoreNet contracts, integrity records, and immutable `upstream/` material without requiring repository-root files.

Telecom-specific extensions are not included yet. See `UPSTREAM.md` for upstream provenance.
