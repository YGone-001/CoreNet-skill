# Protocol Reverse Engineering

An independently usable Foundation Skill for evidence-driven investigation of unknown or partially documented structures. It is Foundation-layer methodology, not authoritative protocol ownership.

Use it for structural comparison, boundary discovery, and documenting uncertainty. Do not use it as a protocol dictionary or for unsupported claims about field meaning.

The package contains a CoreNet wrapper, manifest, provenance records, integrity manifest, and immutable `upstream/` source. Copy the complete directory for standalone use; it needs no repository-root files.

Telecom-specific extensions are not included yet. The pinned upstream source and its metadata are recorded in `UPSTREAM.md`.
