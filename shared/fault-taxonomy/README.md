# Extensible Fault Taxonomy

The repository foundation freezes category names only; it does not encode protocol diagnosis rules.

`RADIO_OR_RAN`, `TRANSPORT`, `IP_ROUTING`, `DNS`, `SCTP`, `TCP`, `UDP`, `IPSEC`, `NAS`, `NGAP`, `S1AP`, `GTP_CONTROL`, `GTP_USER`, `PFCP`, `SBI`, `DIAMETER`, `SIP`, `SDP`, `RTP`, `AUTHENTICATION`, `SUBSCRIBER_DATA`, `POLICY`, `CHARGING`, `QOS`, `USER_PLANE`, `NETWORK_FUNCTION`, `DATABASE`, `CONFIGURATION`, `RESOURCE`, `SOFTWARE_DEFECT`, `INTEROPERABILITY`, and `UNKNOWN` are the initial extensible categories. Future additions must be documented, evidence-safe, and backward-compatible where possible.
