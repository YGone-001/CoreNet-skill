# Naming Rules

- Directories and ordinary file names use lowercase kebab-case.
- Skill names use lowercase kebab-case and match their directory name.
- Canonical exceptions are `README.md`, `SKILL.md`, `UPSTREAM.md`, and `LICENSE`.
- Protocol acronyms may remain uppercase in prose, but not as mixed-case directory names.
- Use `5gc-*` for 5G Core domain Skills, `epc-*` for EPC, and `ims-*` for IMS.
- Do not encode false ownership, such as `ims-diameter`.
- Use `diameter-core`, `diameter-epc`, `diameter-ims`, and `diameter-charging` for the planned Diameter layers.
